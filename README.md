# ClearVue Landing Page

A responsive conceptual landing page for **ClearVue**, a fictional weather-ready eyewear product with an integrated lens-wiping system.

## Files
- `index.html`
- `style.css`
- `script.js`

## How to run
Open `index.html` directly in a modern browser. No build step or server is required.

## Notes
- The eyewear mockups and technical illustrations are built with HTML/CSS, so the page has no broken image dependencies.
- The page includes responsive navigation, scroll-reveal animations, product wiping animations, a before/after comparison slider, and mobile layouts.
